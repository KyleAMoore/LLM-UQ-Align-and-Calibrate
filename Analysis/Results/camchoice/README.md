# CamChoice Results

This directory is intended to hold the files generated at experiment time for the CamChoice dataset. These will be used by the analysis script(s)/notebook(s).

Due to copyright constraints, this dataset only has been scrubbed of any copyrighted material from the original dataset. All data necessary for recreation of the analysis has remained untouched (with the possible exception of some error-prevention code that verifies multi-dataframe matching based on question text columns; such error-prevention asserts should be safely removable without deleterious effects).
