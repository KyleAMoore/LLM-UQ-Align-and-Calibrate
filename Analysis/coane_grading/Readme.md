The parquet files in this folder contain the free response grading results. Each model was graded by two annotators independently, with disagreements/anomalies settled by a third annotator. The original files, with original question and answer text, have been removed for copyright reasons. The current parquet files are identical to the originals apart from the removal of these two columns. The remaining columns were created either by the models or by human annotators and are, by our understanding, not covered by the original copyright.
