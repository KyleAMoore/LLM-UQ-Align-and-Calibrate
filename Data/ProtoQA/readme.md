The dataset has been rearranged using the included ProtoQA_to_parquet.py file to fit the experiment pipeline and expected dataframe format. 58 of the original 8782 questions were removed due to anomalous answer choice counts (i.e. outside the range [2,10]). No other changes/additions/removals were made.
